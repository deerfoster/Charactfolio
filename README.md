
# Charactfolio

App mobile portfolio type developed with Flutter & Dart. Interfaces and every visual element is designed in Pixel Art styles, inspired by the Fields of Mistria game (NPC Studio).


## Technologies

### Lenguajes y Frameworks
* **Flutter:** v3.47.7 (Framework)
* **Dart:** v3.13.4 (programming language)

### Entorno de Desarrollo
* **IDE:** Visual Studio Code v1.143.1 (w/ official flutter & dart extensions)



## Installation

In the IDE terminal:

```bash
git clone https://github.com/deerfoster/Charactfolio.git
```
Look for the project:

```bash
cd charactfolio
```
Installing dependencies:

```bash
flutter pub get
```

Execute the app:

```bash
flutter run
```
    
## Deployment

To download the apk for Android devices:

```bash
flutter build apk --release
```
It will appear on the path:

`build/app/outputs/flutter-apk/app-release.apk`

you can download the apk on the section 'Releases' of this repository.
